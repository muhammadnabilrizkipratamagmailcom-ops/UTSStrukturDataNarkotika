# ADR-002: Strategi Pencarian dan Pengurutan Data

## Status
Diterima

## Konteks
Program membutuhkan fitur pencarian dan pengurutan data putusan pidana narkotika agar pengguna dapat menemukan dan melihat data dengan mudah.

## Keputusan
Pencarian dilakukan berdasarkan nomor putusan atau nama terdakwa. Pengurutan data dilakukan berdasarkan lama pidana penjara.

## Alasan
Strategi ini dipilih agar pencarian data lebih mudah dan hasil pengurutan dapat membantu pengguna membandingkan putusan.

## Konsekuensi
Pengguna dapat mencari data berdasarkan kata kunci dan mengurutkan data berdasarkan lama pidana penjara.
