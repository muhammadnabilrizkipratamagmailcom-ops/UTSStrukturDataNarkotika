
# ADR-001: Pemilihan Struktur Data

## Status
Diterima

## Konteks
Aplikasi membutuhkan struktur data untuk menyimpan dan mengelola 50 data putusan kasus narkotika.

## Keputusan
Menggunakan Singly Linked List sebagai struktur data utama dan Stack sebagai struktur data tambahan.

## Alasan
1. Linked List dapat menambah dan menghapus data secara dinamis.
2. Tidak menggunakan ArrayList atau LinkedList bawaan Java.
3. Stack digunakan untuk menyimpan riwayat aktivitas.
4. Kedua struktur data dibuat secara manual.

## Konsekuensi
Program perlu mengelola hubungan antar-node dan menjaga konsistensi ukuran data.
