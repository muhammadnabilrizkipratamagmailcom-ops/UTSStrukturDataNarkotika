
# Sistem Pengelolaan Putusan Kasus Narkotika

## Deskripsi
Aplikasi Java untuk menyimpan dan mengelola data putusan pengadilan kasus narkotika.

## Tujuan
Menerapkan konsep Pemrograman Berorientasi Objek dan Struktur Data dalam pengelolaan data putusan.

## Struktur Data
- Singly Linked List: struktur data utama untuk menyimpan putusan.
- Stack: struktur data tambahan untuk mencatat riwayat aktivitas.

## Fitur Aplikasi
1. Import data putusan dari CSV.
2. Menampilkan seluruh data putusan.
3. Menambahkan data putusan.
4. Menghapus data putusan.
5. Mencari data berdasarkan ID perkara.
6. Menampilkan riwayat aktivitas.
7. Menampilkan statistik sederhana.

## Teknologi
- Bahasa pemrograman: Java
- IDE: IntelliJ IDEA
- JDK: 25

## Struktur Folder
- src/: kode program Java.
- data/: dataset putusan.
- docs/: dokumentasi dan sumber data.

## Sumber Data
Data putusan akan dikumpulkan dari Direktori Putusan Mahkamah Agung Republik Indonesia.

## Status Pengerjaan
Dalam proses pengembangan dan pengujian.
